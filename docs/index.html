A programmer's editor for machines old and new.

TEDIT is a small, conventional, menu-driven text and code editor built in portable C and plain curses. It sits between nano/JOE/mcedit and a full IDE — without dragging in a modern runtime.

FEATURES

Small editor. Proper tools.

TEDIT keeps the interaction model familiar while adding the features you actually want when writing code on a terminal.

Editing

Multiple buffers, split view, undo/redo, rectangular selection, block indent, comments, line operations, bracket matching and bookmarks.

Syntax

Config-driven highlighting for C/C++, Python, shell, Make, Perl, Fortran, Ada, JSON, Rust, Go, JavaScript and TypeScript.

Projects

Project-root detection, file browser, find-in-files, Build/Clean/Run, captured compiler output and source-location navigation.

Navigator

Two-pane Midnight Commander-style file navigation with copy, move, delete, rename, mkdir, sorting and directory bookmarks.

Recovery

Sessions, recent files, timed recovery snapshots and optional traditional file~ backups.

Portable by design

Plain C, curses and standard Unix interfaces. Keyboard-first operation stays available even on older curses implementations.

BUILD & RUN

One make away.

Clone it, build it, run it. TEDIT's own project configuration makes its in-editor Build command run make and Run launch ./tedit.

$ git clone https://github.com/chriswilson2020/tedit.git $ cd tedit $ make $ ./tedit

Smart standalone builds

Open a lone C source file with no Makefile and TEDIT knows what to do.

hello.c Project → Build $ cc -o hello hello.c Project → Run $ ./hello

For Makefile projects, Build runs make. Add a run=... entry to .tedit-project when the executable cannot be inferred safely.

PLATFORMS

Classic UNIX is a first-class target.

SGI

IRIX 6.5

Explicitly supported, including old curses behaviour and ANSI colour fallback.

ARM

Raspberry Pi

Builds natively with GCC and ncurses. Tiny enough for a Pi Zero-class machine.

x86

Linux

Strict C89 CI builds on Ubuntu. Current stripped x86-64 binary is about 126 KiB.

BSD

BSD / Unix

The code avoids modern runtime dependencies and sticks to conventional Unix interfaces.

THE IDEA

Modern enough to be useful. Old-fashioned enough to run where you actually want it.

TEDIT is intentionally not an IDE disguised as a terminal editor. It gives you menus, project tools, syntax highlighting, navigation, recovery and multiple buffers — while remaining a small C program you can build on a decades-old workstation.
